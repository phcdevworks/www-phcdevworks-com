# Jules Maintenance Checklist

Use this checklist for bounded automated maintenance tasks.

## Scope

- [ ] Task is small and atomic
- [ ] Task does not change brand direction or information architecture
- [ ] Task does not introduce broad formatting churn
- [ ] Task does not absorb unrelated working-tree changes

## Content

- [ ] PHCDevworks remains the parent company framing
- [ ] Spectre remains part of the ecosystem, not the whole site identity
- [ ] Markdown links touched by the task resolve
- [ ] Copy remains concise and technically credible

## Dependencies

- [ ] Dependency changes stay within compatible major lines
- [ ] Lockfile changes are expected
- [ ] No force audit fix was used

## Validation

- [ ] `npm run build` passes when practical
- [ ] Skipped validation is explained
- [ ] Handoff lists files changed
